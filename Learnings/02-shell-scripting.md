*   Creating files

*   Starting services
    
*   Stopping services
    
*   Checking servers
    
*   Checking disk usage
    
*   Checking processes
    
*   Managing logs
    
*   Taking backups
    
*   Deploying applications
    
*   Running tests
    
*   Monitoring systems
